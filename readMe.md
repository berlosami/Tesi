# Istruzioni per l'esecuzione

1. Installa Visual Studio Code.
2. Installa le estensioni consigliate nel file `.vscode/extensions.json` (compare un pop-up in basso a destra).
3. Crea un ambiente virtuale Python e installa i requisiti:
   - `Ctrl+Shift+P`
   - `Python: Create Environment...`
   - Seguire il wizard, spuntare la casella per installare `requirements.txt`
   - `Ctrl+Shift+P`
   - `Developer: Reload Window`
4. Avvia uno dei file presenti nella cartella `/impulsivity`.
